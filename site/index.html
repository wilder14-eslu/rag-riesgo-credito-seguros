    Qué corre en esta página

    Recuperación
    Embeddings por hashing + BM25, fusionados con RRF y reordenados por cobertura léxica. Sin llamadas a ningún LLM: las respuestas extraen oraciones del texto y las citan.
    Seguridad
    Detección de inyección de prompt, enmascarado de DNI, RUC, tarjetas y correos, verificación de que cada oración tenga respaldo, y abstención si la evidencia es débil.
    Modelo de default
    XGBoost en ONNX (271 KB). Se verificó contra el modelo original en 4,000 filas con diferencia máxima de 5×10⁻⁷.
    Equivalencia con Python
    Una prueba automática compara este motor con el de Python en cada despliegue: preguntas, clasificaciones y provisiones deben coincidir carácter por carácter.

    El corpus es de ejemplo y las cifras sirven para mostrar el funcionamiento, no como referencia regulatoria. La probabilidad de default viene de un modelo entrenado con datos públicos de Kaggle y no debe usarse para decisiones reales sobre personas.
